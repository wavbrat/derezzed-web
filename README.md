# Derezzed Web

Demo público PWA — editor optimizado para iPhone 16e.

Este repositorio contiene la versión pública de prueba (derezzed-web). Incluye imágenes de ejemplo y un logo provisional.

Cómo probar en iPhone:
1. Abre https://wavbrat.github.io/derezzed-web/ en Safari (despliegue automático via GitHub Actions; puede tardar unos minutos la primera vez).
2. Usa el botón Compartir → "Agregar a pantalla de inicio" para instalar la PWA.

Notas:
- El repositorio público se usa solo para pruebas. El repo privado principal es "derezzed-pwa".
- Para integrar Google Drive, en próximas entregas añadiré una página de Ajustes para pegar `client_id` y activar OAuth PKCE desde el iPhone.
